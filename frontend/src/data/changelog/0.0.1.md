### Improved Authentication
--- 
Switched from Localstorage for authentication to **HttpOnly Cookie** for improved sequirity.
HttpOnly Cookie needs to be in the same origin as backend.

For that Add These in the .env
```bash
VITE_URL=http://192.168.29.118:5173 
VITE_SERVER_PORT=8000                           
```
- **VITE_URL** : This will be the same origin for backend and frontend
- **VITE_SERVER_PORT** : This will be the port in which server will be on.
